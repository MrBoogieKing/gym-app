# 🏋️ Gym Log

Простий щоденник тренувань для iPhone (PWA). Програми, підходи, вага, прогрес. Працює без інтернету, без реєстрації, без залежностей.

## Можливості

- **Програми тренувань**: дні (Push / Pull / Legs тощо) і вправи з планом «підходи × повтори».
- **Тренування**: вага й повтори для кожного підходу, відмітка ✓.
  - «Минулого разу» біля кожної вправи.
  - Автопідстановка ваги з минулого тренування або попереднього підходу: часто достатньо просто натиснути ✓.
  - Кнопки −/+ для ваги (крок налаштовується).
  - Таймер відпочинку з сигналом, стартує сам після кожного ✓.
  - 🏆 позначка нового рекорду.
  - Підказка «спробуй +2.5 кг», коли минулого разу план виконано.
- **Головний екран**: план на сьогодні, тиждень днями, кільце прогресу до тижневої цілі.
- **Календар**:
  - Вибраний день показує, що робив: вправи, підходи, вага.
  - Майбутній день: вибираєш, яке тренування плануєш.
  - Сьогодні: почати одразу. Минулий день: дописати забуте тренування.
  - Позначки «був у залі» / «відпочинок», нотатки, серія тижнів поспіль.
  - Вкладка «Історія» зі списком усіх тренувань.
- **Тіло**: вага, % жиру, обхвати з графіками та змінами; фото прогресу з порівнянням «До / Зараз».
- **Прогрес**: графік по кожній вправі (1ПМ, макс. вага, об’єм) і рекорди.
- **Резервна копія** (разом із фото): збереження в «Файли» / iCloud / Telegram і відновлення з файлу.

## Встановлення на iPhone

1. Відкрий посилання на апку в **Safari**.
2. Натисни **Поділитися** → **На екран «Додому»**.
3. Запускай з іконки, як звичайну апку.

> Дані зберігаються тільки на телефоні. Час від часу роби резервну копію: ⚙️ → «Зберегти копію».

## Розробка

Без збірки: звичайні HTML, CSS і JS.

```bash
python -m http.server 5173
# відкрий http://localhost:5173
```

Файли:
- `index.html`: точка входу
- `app.js`: уся логіка (дані, екрани, події)
- `styles.css`: стилі
- `sw.js`: офлайн-кеш (при кожному релізі збільшуй `CACHE` версію)
- `manifest.webmanifest`, `icons/`: PWA-налаштування та іконки
